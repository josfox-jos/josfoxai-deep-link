# josfoxai-deep-link (reserved name)

This repository name is reserved by JOSFOX and holds no code. The deep-link helper that opens the JOSFOX AI app lives in **[josfox-ai/josfoxai-deep-link](https://github.com/josfox-ai/josfoxai-deep-link)**; please open issues and pull requests there.

Why reserve it: the same package name under both JOSFOX organizations prevents a look-alike repository from being mistaken for an official one.
